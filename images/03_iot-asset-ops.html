App Architecture

핵심 기능

스캔 기반 자산 관리
S/N 바코드 스캔 → 선반 QR 스캔으로 입고·이동·반납을 처리. 선반 포화 감지, 수동 입력 fallback, 이미 등록된 제품 자동 감지
대여·반납·폐기 이력 관리
대여위치·사용자 기록, Google Sheets 비고 자동 기재. 폐기 지정 시 취소선 서식 적용, 확정 전 상태 구분 보존
통계 대시보드 + PDF 출력
제품군 필터·도넛 차트·랙별 드릴다운. 자산 다중 선택 → A4 바코드 카드 PDF 생성 → Drive 업로드 → 이메일 발송 원클릭
통합 검색 · 동의어 자동 확장
현위치·제품군·제품명·모델명·S/N 등 다중 조건 통합 검색. 키워드 동의어 자동 확장 검색 지원 (SQLite synonym 테이블)
