Smart Factory Data Pipeline

PLC 센서 데이터를 MQTT로 수집해 실시간 집계·이상 탐지·모니터링까지 구현해본 개인 학습 프로젝트. MQTT 프로토콜, 시계열 데이터 처리, 통계적 공정관리(SPC) 개념을 직접 설계·구현하며 익혔습니다.

QoS 불일치 버그 직접 발견·수정

SPC 이상 탐지
관리도(Control Chart)의 UCL·LCL 고정 기준값을 벗어나는 습도값을 수신 즉시 비교·탐지, 측정값·기준값·초과유형을 별도 테이블에 기록해 Grafana에서 위반 이력 시각화
※ UCL = Upper Control Limit(관리상한) · LCL = Lower Control Limit(관리하한)
